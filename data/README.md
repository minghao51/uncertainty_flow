# Benchmark Datasets

Benchmark datasets for testing and development of `uncertainty_flow`.

## Datasets

### Time Series (Original)

| Dataset | Rows | Columns | Size | Target | UQ Challenge |
|---------|------|---------|------|--------|--------------|
| `weather.parquet` | 36,887 | 22 | 1.78 MB | `OT` | Smooth, near-Gaussian, multivariate |
| `exchange_rate.parquet` | 5,311 | 9 | 0.23 MB | `OT` | Low-dimensional, mild non-stationarity |
| `electricity.parquet` | 26,304 | 321 | 14.72 MB | `OT` | High-dimensional, periodic |

### Time Series (Diverse)

| Dataset | Rows | Columns | Size | Target | UQ Challenge |
|---------|------|---------|------|--------|--------------|
| `traffic.parquet` | 12,280 | 1 | 0.03 MB | `OT` | Regime changes, rush-hour patterns |
| `illness.parquet` | 676 | 8 | 0.02 MB | `OT` | Regime-switching, seasonal, small sample |

### Tabular (UCI)

| Dataset | Rows | Columns | Size | Target | UQ Challenge |
|---------|------|---------|------|--------|--------------|
| `concrete.parquet` | 1,030 | 9 | 0.01 MB | `strength` | Heteroscedastic, non-linear |
| `wine_quality.parquet` | 1,599 | 12 | 0.03 MB | `quality` | Ordinal, non-Gaussian |
| `energy_efficiency.parquet` | 768 | 10 | <0.01 MB | `y1` | Multi-target, heteroscedastic |

### Synthetic (Ground Truth)

| Dataset | Rows | Columns | Size | Target | UQ Challenge |
|---------|------|---------|------|--------|--------------|
| `synthetic_heteroscedastic.parquet` | 5,000 | 7 | 0.26 MB | `y` | Known variance function (ground truth) |
| `synthetic_regime_switching.parquet` | 5,000 | 2 | 0.04 MB | `y` | Known structural breaks |
| `synthetic_heavy_tailed.parquet` | 5,000 | 7 | 0.26 MB | `y` | Student-t(3) noise, kurtosis > 9 |

## Usage

```python
import polars as pl
from uncertainty_flow.models import QuantileForestForecaster

# Load dataset
df = pl.read_parquet("data/weather.parquet")

# Train model
model = QuantileForestForecaster(targets="OT", horizon=3, n_estimators=50)
model.fit(df)

# Predict
pred = model.predict(df)
print(pred.interval(0.9))
```

## Ingestion

```bash
# Ingest all datasets
uv run python benchmarks/ingest_datasets.py --group all

# Ingest specific groups
uv run python benchmarks/ingest_datasets.py --group original
uv run python benchmarks/ingest_datasets.py --group tabular
uv run python benchmarks/ingest_datasets.py --group ts-diverse
uv run python benchmarks/ingest_datasets.py --group synthetic
```

## Benchmarking

```bash
# Run benchmarks on all datasets
uv run python benchmarks/run_benchmarks.py --all-datasets

# Run specific dataset groups
uv run python benchmarks/run_benchmarks.py --dataset-group ts
uv run python benchmarks/run_benchmarks.py --dataset-group tabular
uv run python benchmarks/run_benchmarks.py --dataset-group synthetic

# Run single dataset
uv run python benchmarks/run_benchmarks.py -d concrete -n 500
```
